# Morning Dashboard

새 탭을 열면 오늘 할 일, 진행 중인 작업, 어제 남긴 메모가 보이는 아침 투두 대시보드.
HTML, CSS, Vanilla JS로 만들었고 데이터는 브라우저 localStorage에 저장한다.

## 크롬 확장으로 설치하기

1. 이 저장소를 내려받는다.
   ```bash
   git clone https://github.com/semo08/morning-dashboard.git
   ```
2. 크롬 주소창에 `chrome://extensions`를 입력한다.
3. 오른쪽 위 **개발자 모드**를 켠다.
4. **압축해제된 확장 프로그램 로드**를 누르고 `morning-dashboard` 폴더를 선택한다. 폴더 안의 파일이 아니라 폴더 자체를 고른다.
5. 새 탭(Ctrl+T)을 연다. "이 확장 프로그램이 새 탭 페이지를 변경했습니다"라는 팝업이 뜨면 **변경사항 유지**를 누른다.

크롬은 내 컴퓨터의 폴더를 직접 읽어서 실행한다. 그래서 폴더를 지우거나 옮기면 확장도 동작하지 않는다.

## 업데이트하기

1. 최신 코드를 받는다.
   ```bash
   cd morning-dashboard
   git pull
   ```
2. `chrome://extensions`에서 Morning Dashboard 카드의 🔄 **새로고침**을 누른다.
3. 열려 있던 새 탭을 새로 연다.

코드를 직접 고쳤을 때도 2~3번을 하면 반영된다. 업데이트해도 저장된 데이터는 그대로 남는다.

## 데이터 옮기기

데이터는 컴퓨터마다, 또 확장과 웹 주소(`localhost`)마다 따로 저장된다. 다른 PC나 확장으로 옮기려면:

1. 원래 쓰던 화면에서 🎨 꾸미기 → **데이터 옮기기 → 내보내기**를 누르면 `morning-dashboard-날짜.json` 파일이 받아진다.
2. 옮길 곳에서 🎨 꾸미기 → **가져오기**로 그 파일을 고른다.

가져오면 지금 있는 데이터가 파일 내용으로 **통째로 바뀐다**. 할 일, 폴더, 작업 보드, 메모, D-day, 잔디, 테마, 배경 사진이 모두 옮겨진다.

## 웹으로 개발하기

ES 모듈을 쓰기 때문에 파일을 더블클릭해서 열면 동작하지 않는다. 로컬 서버로 연다.

```bash
python -m http.server 5517
```

그다음 http://localhost:5517 에 접속한다. 기획과 데이터 구조는 [docs/PLAN.md](docs/PLAN.md)에 있다.
